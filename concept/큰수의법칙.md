# 큰 수의 법칙

다양한 수로 이루어진 배열이 있을 때 주어진 수들을 M번 더하여 가장 큰 수를 만드는 법칙. 단, 배열의 특정한 인덱스(번호)에 해당하는 수가 연속해서 K번을 초과하여 더해질 수 없음.

**입력 조건**
- 첫째 줄에 N(2$\leq$N$\leq$1,000), M(1$\leq$M$\leq$10,000), K(1$\leq$K$\leq$10,000)의 자연수가 주어지며, 각 자연수는 공백으로 구분한다.
- 둘째 줄에 N개의 자연수가 주어진다. 각 자연수는 공백으로 구분한다. 단, 각각의 자연수는 1 이상 10,000 이하의 수로 주어진다.
- 입력으로 주어지는 K는 항상 M보다 작거나 같다.

**출력 조건**
- 큰 수의 법칙에 따라 더해진 답을 출력한다.

```python
# 입력 예시
5 8 3
2 4 5 4 6

# 출력 예시
46
```

**나의 풀이** $\mathcal{O(N^2+M)}$
```python
N, M, K = map(int, input().split())
arr = list(map(int, input().split()))
dup = arr.copy()
fir_max = max(arr)

# 가장 큰 수가 2번 이상 나올 때는 항상 M배가 답이다.
def check_max_num(arr):
    m = max(arr)
    num = 0

    while m in arr:
        num += 1
        arr.remove(m)
    return num


if check_max_num(dup) >= 2:
    print(fir_max*M)

# 가장 큰 수가 1번 나오면 두 번째로 큰 수를 구해야 한다.
else:
    res = 0
    cnt = 0
    sec_max = max(dup)
    for i in range(M):
        if cnt == K:
            res += sec_max
            cnt = 0
            continue
        else:
            res += fir_max
            cnt += 1

    print(res)
```

**문제 해설** $\mathcal{O(NlogN)}$
```python
# N, M, K를 공백으로 구분하여 입력받기
N, M, K = map(int, input().split())

# N개의 수를 공백으로 구분하여 입력받기
data = list(map(int, input().split()))

data.sort()
first = data[N - 1]
second = data[N - 2]

# 가장 큰 수가 더해지는 횟수
count = (M // (K + 1)) * K
count += M % (K + 1)

result = count * first
result += (M - count) * second

print(result)
```

**다른 풀이** $\mathcal{O(N)}$
```python
N, M, K = map(int, input().split())
data = list(map(int, input().split()))

first = float("-inf")
second = float("-inf")

for number in data:
    if number > first:
        second = first
        first = number
    elif number > second:
        second = number

count = (M // (K + 1)) * K
count += M % (K + 1)

result = count * first + (M - count) * second
print(result)
```
